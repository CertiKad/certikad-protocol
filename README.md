## Overview

CertiKad is a decentralized standard aiming to be the system-of-record for verifiable professional merit. It unifies all types of credentials—both institutional (like degrees, certifications) and experiential (like client attestations, DAO work)—into a UniversalProfessionalLedger that is self-sovereign (ERC-721), immutable, and portable.

## 🏗️ Architecture

### Smart Contracts (ERC-721)
- **Self-sovereign credentials** - Users own their professional merit records
- **Immutable ledger** - Tamper-proof credential storage
- **Portable credentials** - Transfer between platforms and ecosystems

### Frontend Application
- **User-friendly interface** for credential management
- **Verification system** for institutional and experiential credentials
- **Portfolio view** of professional achievements
